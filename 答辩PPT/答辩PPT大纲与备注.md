## 三、使用说明

### 3.1 浏览器直接展示（推荐）

```
1. 双击打开 答辩PPT.html（Chrome / Edge 最佳）
2. 按 F 键进入全屏模式（或底部控制栏「全屏」按钮）
3. ← → 方向键 / PageUp PageDown / 空格键 翻页
4. 完成后按 ESC 退出全屏
```

### 3.2 导出 PDF / 打印

```
底部控制栏 → 「PDF 导出」按钮（或 Ctrl+P）
→ 目标打印机：另存为 PDF
→ 纸张：横向，尺寸：A4 或 1280×720 自定义
→ 边距：无
→ 选项：取消「页眉和页脚」
→ 保存
```

### 3.3 转 PowerPoint（.pptx）

方案 A：用 LibreOffice Impress 导入 HTML 后另存为 PPTX（样式可能需要微调）
方案 B：将 PDF 用 `Adobe Acrobat` → `导出为 PPTX`（效果较好）
方案 C：直接截图每页转图片，粘贴进 PPT（最稳妥不跑样式）

### 3.4 替换占位图片

HTML 中所有虚线斜纹区域均为图片占位。替换方法：
1. 在 HTML 代码中搜索 `【插入：` 即可定位所有占位
2. 将 `<div class="img-ph">...</div>` 整块替换为：
```html
<img src="./images/your-file.png" style="width:100%;height:100%;object-fit:cover;border-radius:6px;">
```
3. 或将截图文件放入 `答辩PPT/images/` 目录，按上表文件名对应命名即可。
