## 替换占位图片的 HTML 代码方式

步骤 1：在本目录（`答辩PPT/`）下新建 `images` 文件夹，将所有截图放入

```
答辩PPT/
├── 答辩PPT.html
├── 答辩PPT大纲与备注.md
└── images/
    ├── img-01-overview.png
    ├── img-02-risk.png
    ├── img-03-ai.png
    └── ...（其他图片）
```

步骤 2：打开 `答辩PPT.html`，搜索 `【插入：`，每命中一个就是占位区

步骤 3：将整段 `.img-ph` 代码块替换为 `<img>` 标签。例如：

替换前：
```html
<div class="img-ph res-img">
  <div class="ph-label">【图 1：综合态势模块（overview）】</div>
  <div class="ph-tip">飞线辐射 + 时段天空 + KPI 卡片 + 左右图表列</div>
</div>
```

替换后：
```html
<img src="./images/img-01-overview.png" 
     style="width:100%;height:100%;object-fit:cover;border-radius:6px 6px 0 0;"
     class="res-img"
     alt="综合态势模块">
```

> 不同占位区对应的 CSS 类不同：
> - 成果展示四宫格：保留 `class="res-img"`，border-radius 去掉右下/左下
> - 架构图大图：`style="width:100%;height:100%;object-fit:contain;border-radius:6px;"`
> - 三小图（左下/中下/右下）：`style="width:100%;height:100%;object-fit:contain;border-radius:6px;"`
